# ScanSeries 🎬

Bem-vindo ao ScanSeries! Este é um projeto de front-end que cria uma interface web elegante para navegar e pesquisar por uma vasta coleção de filmes e séries. A aplicação carrega os dados de um arquivo JSON local e os exibe em um layout de cards responsivo e moderno.

## ✨ Funcionalidades

- **Visualização em Cards:** Navegue por filmes e séries apresentados em um layout de grade limpo e organizado.
- **Dados Dinâmicos:** Todo o conteúdo é carregado dinamicamente a partir de um arquivo `data.json`, facilitando a adição e gerenciamento de novos títulos.
- **Busca em Tempo Real:** Filtre o conteúdo instantaneamente usando a barra de pesquisa no cabeçalho.
- **Design Responsivo:** A interface se adapta a diferentes tamanhos de tela, garantindo uma boa experiência tanto em desktops quanto em dispositivos móveis.
- **Efeitos de Hover:** Efeitos visuais sutis nos cards para uma melhor interatividade com o usuário.
- **Estrutura Completa:** Layout bem definido com cabeçalho, banner, conteúdo principal e rodapé fixo.

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias web padrão:

- **HTML5:** Para a estrutura semântica da página.
- **CSS3:** Para toda a estilização, utilizando recursos modernos como:
  - **Flexbox:** Para alinhar elementos nos cabeçalhos e rodapés.
  - **Grid Layout:** Para criar o layout responsivo dos cards.
  - **Gradientes e Transições:** Para um visual mais polido e interativo.
- **JavaScript (Vanilla):** Para a manipulação do DOM, busca de dados (fetch API) do `data.json` e implementação da funcionalidade de pesquisa.

## 🛠️ Como Executar

Como este é um projeto puramente de front-end, você não precisa de um servidor complexo para executá-lo.

1.  **Clone o repositório:**
    ```bash
    git clone <url-do-seu-repositorio>
    ```
2.  **Navegue até a pasta do projeto:**
    ```bash
    cd imersion
    ```
3.  **Abra o arquivo `index.html`** no seu navegador de preferência (Google Chrome, Firefox, etc.).

E pronto! A aplicação estará funcionando.
